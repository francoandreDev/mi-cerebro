# mi-cerebro

**Antes de responder al usuario o tocar cualquier archivo en este repo, leé `docs/proyecto/index.md` y `docs/proyecto/reglas.md` completos**, y después el/los archivo(s) de tema relevantes a la tarea según la tabla de `index.md` (features.md, filesystem.md, roadmap-\*.md, etc.). `docs/proyecto/` es la single source of truth del proyecto: visión, alcance, stack, reglas de código/arquitectura, esquema de errores, estructura del FS del usuario, roadmap — repartida en varios archivos porque un único doc creció demasiado pesado de leer de una (ver `docs/proyecto/index.md` para el porqué). Cualquier decisión de diseño o implementación se valida contra esos documentos.

Si una tarea propone algo que contradice `docs/proyecto/`, decirlo antes de implementar y proponer actualizar el documento correspondiente primero (regla §4.11.25 en `docs/proyecto/reglas.md` — el commit que cambia una decisión arquitectónica también actualiza el archivo de `docs/proyecto/` correspondiente, en el mismo commit).

Idioma: UI en español, código y commits en inglés.
