# mi-cerebro

**Antes de responder al usuario o tocar cualquier archivo en este repo, leé `PROYECTO.md` completo.** Es la single source of truth del proyecto: visión, alcance, stack, reglas de código/arquitectura, esquema de errores, estructura del FS del usuario, roadmap. Cualquier decisión de diseño o implementación se valida contra ese documento.

Si una tarea propone algo que contradice `PROYECTO.md`, decirlo antes de implementar y proponer actualizar el documento primero (regla §4.11.25 — el commit que cambia una decisión arquitectónica también actualiza `PROYECTO.md`, en el mismo commit).

Idioma: UI en español, código y commits en inglés.
